## Name
MarkNote — Local-first Markdown notes for macOS

## One-liner (tagline)
"Notes are just files. AI built in. Your data stays yours."

## Short description (under 255 chars)
A local-first Markdown notes app for macOS. Every note is a plain .md file in a folder — switch editors, back up, put it in git. Built-in DeepSeek AI assistant, declarative plugins, offline render pipeline (KaTeX/Mermaid/hljs). SwiftUI, no Electron bloat.

## 3 bullet features
- **Notes = files**: a workspace is just a folder; images/PDFs auto-sort into source/ and reference inline
- **AI assistant (built-in)**: @file references, read/write file agent, conversation history, summarize-to-note. No API key setup
- **Trimmable & plugin-based**: core is write→view→save; line numbers, export, AI quick actions, render extensions — each a switch; plugin market with declarative packages

## First comment (maker)
Hi Product Hunt! I built MarkNote because I kept bouncing between Obsidian (files but heavy), Bear (pretty but locked data), and Typora (great editing, no AI). So I combined the three: every note is a plain .md file, AI is built in (DeepSeek, no API key), and everything non-essential is a plugin or a toggle. Built natively with SwiftUI + AppKit — no Electron. Happy to answer anything!
