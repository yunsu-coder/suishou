# 随手 · 内置插件库

插件为声明式包(manifest.json + 数据文件,不执行用户代码),在插件市场启用/禁用。仓库 `plugins-market/`;全局安装目录 `~/Library/Application Support/MarkNote/plugins/`。

## 渲染扩展(预览新语法)

| 包 | 能力 | 语法示例 |
| --- | --- | --- |
| render-kbd | 键帽样式 | `[[⌘S]]` → `<kbd>` 键帽 |
| render-mention | 提及高亮 | `@名字` → 高亮提及 |
| render-quote | 引言美化 | 块引用 → 卡片样式 |
| render-term | 终端代码块 | 连续 `$ command` 行 → 终端风格 |
| render-copy | 代码块复制按钮 | 每个代码块右上角一键复制 |

## 模板包作者注意

snippets.json 的 `text` 字段:JSON 转义 `\n` 解码为换行;误写 `\\n` 会得到字面反斜杠+n(应用侧已有容错,但新包建议写正确形式)。
