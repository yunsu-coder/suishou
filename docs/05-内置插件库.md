# 随手 · 内置插件库

> 纯增量声明式插件包(无代码执行,零崩溃风险):即装即用(插件市场 → 启用)。仓库位置 `plugins-market/`;全局安装目录 `~/Library/Application Support/MarkNote/plugins/`。

## 渲染扩展(预览新语法)

| 包 | 能力 | 语法示例 |
| --- | --- | --- |
| render-kbd | 键帽样式 | `[[⌘S]]` → 键盘键帽 `<kbd>` |
| render-mention | 提及高亮 | `@名字` → 高亮提及 |
| render-quote | 引言美化 | 块引用 → 引言卡片(左侧大引号+底色) |
| render-term | 终端风味代码块 | 连续 `$ command` 行 → 黑底绿字终端块 |

## 模板包(命令面板「插入:…」)

| 包 | 模板 |
| --- | --- |
| snip-writing | 周报 / 会议纪要 / PRD / 复盘 |
| snip-dev | README / API 文档 / CHANGELOG / 代码审查清单 |
| snip-study | 康奈尔 / 费曼 / 错题本 / 读书笔记 |
| snip-email | 正式 / 跟进 / 请假 邮件 |
| snip-plan | OKR / 项目计划 / 健身周计划 |

模板正文中英双语(`textEn`):英文界面插入英文 Markdown,中文界面插入中文。

## 已移除(与内置功能重复)

早期版本曾包含 AI 专家包(exp-*)、命令包(cmd-*)、文件类型包(ft-*)、主题包(theme-*)与示例包(demo-*)—— 这些与内置功能重复,已从市场与安装目录移除(2026-09),市场只保留纯增量插件。

## 使用

- 插件市场(左侧功能栏 🧩)→ 逐包启用;渲染包即刻生效(指纹重渲)
- 模板进命令面板(⌃⇧P);卸载 = 市场内一键卸载
- 包元数据(name/desc/features)与市场 UI 均双语

## 模板包作者规范(重要)

snippets.json 的 `text` 字段必须用真实 JSON 转义:`\n` 解码为换行;误写 `\\n` 会得到字面反斜杠+n,插入后一行挤到底。

应用侧已内置容错(`PluginManager.normalizeText`):误写双反斜杠的老包自动修正为换行,无需重打包;新包仍应写单反斜杠。
