# 随手 · 内置插件库

插件为声明式包(manifest.json + 数据文件,不执行用户代码),在插件市场启用/禁用。仓库 `plugins-market/`;全局安装目录 `~/Library/Application Support/MarkNote/plugins/`。

## 渲染扩展

| 包 | 能力 | 语法示例 |
| --- | --- | --- |
| render-kbd | 键帽样式 | `[[⌘S]]` → `<kbd>` 键帽 |
| render-mention | 提及高亮 | `@名字` → 高亮提及 |
| render-quote | 引言美化 | 块引用 → 卡片样式 |
| render-term | 终端代码块 | 连续 `$ command` 行 → 终端风格 |

## 模板包(命令面板「插入:…」)

| 包 | 模板 |
| --- | --- |
| snip-writing | 周报 / 会议纪要 / PRD / 复盘 |
| snip-dev | README / API 文档 / CHANGELOG / 代码审查清单 |
| snip-study | 康奈尔 / 费曼 / 错题本 / 读书笔记 |
| snip-email | 正式 / 跟进 / 请假 邮件 |
| snip-plan | OKR / 项目计划 / 健身周计划 |

模板正文有中英两版(textEn):英文界面插入英文,中文界面插入中文。

## 移除记录

早期曾包含 AI 专家包(exp-*)、命令包(cmd-*)、文件类型包(ft-*)、主题包(theme-*)与示例包(demo-*),与内置功能重复,2026-09 已从市场与安装目录移除。

## 使用

- 插件市场(左侧 🧩)→ 启用;渲染包需要重渲染后生效
- 模板进命令面板(⌃⇧P);卸载在市场内
- 包元数据与市场 UI 有中英文

## 模板包作者注意

snippets.json 的 `text` 字段:JSON 转义 `\n` 解码为换行;误写 `\\n` 会得到字面反斜杠+n,插入后一行挤到底(应用侧已有容错,但新包建议写正确形式)。
