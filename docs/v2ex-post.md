我做了个 Mac 上的 Markdown 笔记软件:文件即笔记,带 AI —— 随手(MarkNote)

写笔记/做记录折腾过不少工具(Typora/Bear/Obsidian/Notion),最后决定不如自己做一个。核心思路很简单:**笔记就是一个普通 .md 文件,工作台就是一个文件夹**。没有私有格式,不锁库,想换编辑器、想备份迁移、想放进 git,都直接可用。

### 关键设计

- **文件即笔记**:每篇笔记对应一个 .md 或文本文件,文件夹即分类,图片/PDF 等资源按类型自动归到 source/ 下并插入引用
- **AI 内置(DeepSeek)**:停靠式面板(⇧⌘A),支持 @文件名 引用工作台文件做上下文、文件读写代理(能帮你改名/移动/删除)、对话历史、一键总结进笔记。不用配 API key,开箱即用
- **功能可裁剪**:写→看→存 是核心,行号/当前行高亮/括号匹配/代码智能/导出/AI 快捷操作/渲染扩展 都是开关,设置里逐项控制
- **插件化**:声明式插件包(不执行用户代码),已内置按键帽/提及高亮/引言美化/终端代码块等渲染扩展和周报/PRD/康奈尔等模板包,市场里一键启用
- **离线渲染**:markdown-it + KaTeX + Mermaid + highlight.js 全离线,公式图表代码高亮不联网也能渲
- **性能**:SwiftUI + AppKit 纯原生,预览只用一个 WKWebView,没有 Electron 包袱,启动和打字都轻快

### 技术栈

Swift 5.10 / SwiftUI + AppKit / SPM 可执行目标 / macOS 14+

### 为什么做在 macOS 上

macOS 上其实不缺笔记软件,但「文件即笔记 + AI + 可裁剪」这个组合目前没有特别顺手的选择。Obsidian 文件是文件,但重量;Bear 好看,但数据私有;Typora 编辑体验一流,但没有 AI 和插件。我想把这三者的优点合并到一个轻量软件里。
