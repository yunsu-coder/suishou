# 流程图 · Flowchart（视图插件）

在**当前工作台**里画流程图：图形、连线、文字、分组、样式美化，导出 PNG。
图和产物都在本工作台内，卸载即干净。

## 声明（views.json）

| 字段 | 值 | 说明 |
| --- | --- | --- |
| `type` | `flowchart` | app 内置渲染器，插件不提供代码 |
| `scope` | `workspace` | 读写当前工作台的 `source/flowchart/`；不允许 `global`（扫描阶段拦截） |
| `placement` | `main` | 占主区域，侧栏出现「树 / 卡片 / 流程图」切换（面板形态会被判不合格） |

## 数据与产物

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 图（可继续编辑） | `<工作台>/source/flowchart/<名字>.json` | 纯 JSON，可读、可进 git；同重名自动加序号，不覆盖 |
| 导出的图片 | `~/Downloads/随手导出/<名字>.png` | 1x / 2x / 3x，背景可选主题纸色 / 白色 / 透明 |

编辑时 0.9 秒防抖自动保存；`⌘S` 立即保存。删除图走系统废纸篓，可随时恢复。

## 操作

| 动作 | 方式 |
| --- | --- |
| 画图形 | 选一个图形工具，在画布上拖；或单击（用默认尺寸落一个） |
| 连线 | 拖图形四边的圆点，或切「连线」工具从图形上拖到另一个图形 |
| 写文字 | 双击图形 / 连线标签 / 分组标题 |
| 选择 | 单击；`⇧` 单击加选；空白处拖拽框选；`⌘A` 全选 |
| 平移 / 缩放 | `⌥` 拖拽或双指滚动平移；`⌘` + 滚轮（或捏合）缩放；工具栏有「适应窗口」 |
| 微调 | 方向键 1pt，`⇧` + 方向键 10pt；拖动时自动吸附对齐并显示参考线 |
| 编辑 | `⌘Z` / `⇧⌘Z` 撤销重做，`⌘D` 复制，`⌘E` 自动编号，`⌫` 删除，`Esc` 取消选中 |

## 主题适配

工具栏、检查器、网格、默认配色与字体全部取当前主题变量
（`--bg` / `--surface` / `--text` / `--accent` / `--md-*` 与主题字体），四套主题下自动适配。

> **颜色例外（2026-09 规范修订）**：流程图是画图工具，图形与连线的颜色允许用户自选
> （调色板取自主题派生色，另可取色器任选）。界面外壳仍必须跟随主题，不得写死色值。
